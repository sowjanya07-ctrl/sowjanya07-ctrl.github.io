A responsive personal portfolio website showcasing my software engineering projects, data analytics pipelines, technical milestones, and community initiatives.

---

## ⚡ Tech Stack & Architecture

- **Markup & Styling:** Semantic HTML5, Modern CSS3 (Grid, Flexbox, CSS Variables, Backdrop Blur)
- **Typography:** DM Sans & Space Grotesk via Google Fonts
- **Interactivity:** Vanilla JavaScript for responsive mobile navigation
- **Deployment:** Hosted with GitHub Pages

---

## 🚀 Key Features

- **Performance-First:** Zero heavy frameworks or runtime dependencies for instant load times.
- **Responsive Layout:** Adaptive design engineered for mobile devices, tablets, and wide-screen desktops.
- **Structured Showcase:** Dedicated sections for core projects, skill domains, academic/hackathon milestones, and contact channels.
